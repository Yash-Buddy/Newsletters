Each issue is two parts: a short **email** that lands in the inbox, and an **interactive page** the reader opens with one click.

| 01 Email | 02 Click | 03 Explore |
|---|---|---|
| Static cards that work in Gmail and Outlook | A button opens the live interactive page | Hover tooltips, toggles, animated charts |

## What's inside

- **Email version:** tables and inline styles, so it works in Gmail and Outlook.
- **Interactive page:** Recharts charts with hover tooltips, toggles and animation, hosted with GitHub Pages.

## Folder structure

    index.html          latest issue (interactive page)
    issues/YYYY-MM/     older issues, one folder each
    emails/             email HTML files to paste or send

## Notes

- Data in the demo issue is fake sample data.
- Hover effects and web fonts appear in browsers and Apple Mail. Gmail and Outlook show the normal version.
